# CSV Tabulator

[Link](https://csv-tabulator.vercel.app/)

A lightweight React application to upload and view CSV files in a table format with pagination.

## Features

- **Upload CSV:** Easily upload CSV files from your local machine.
- **Table View:** Displays CSV content in a clean, responsive table.
- **Pagination:** View large CSV files with pagination support (10 rows per page).
- **Responsive Design:** Built with Tailwind CSS for a modern look on any device.

## Technologies Used

- **Framework:** [React](https://react.dev/)
- **Build Tool:** [Vite](https://vite.dev/)
- **Language:** TypeScript
- **Styling:** Tailwind CSS

## Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm or yarn

## Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/csvTabulator.git
    cd csvTabulator
    ```

2.  **Install dependencies:**
    ```bash
    cd frontend
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

4.  **Open in browser:**
    Navigate to the URL provided in the terminal (usually `http://localhost:5173`).

## Available Scripts

In the `frontend` directory:

- `npm run dev`: Starts the development server.
- `npm run build`: Builds the application for production.
- `npm run lint`: Runs the linter.
- `npm run preview`: Previews the production build.
